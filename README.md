# HycarPerd

スマホでも動く、なんちゃってHyperCard。白黒のクラシックMac風UIと、HyperTalk風の簡易言語を持つ。

## 起動

```sh
python3 -m http.server
```

`http://localhost:8000` を開く（`index.html` を直接開くとサンプルを読み込めない）。

起動すると、ホームのスタック（`stacks/HOME.stack.json`）を表示する。ボタンの `doMenu` や `go stack` でスタックを開く。
ホームのスタックは変更しても保存の確認の対象にしない。

## 画面

端末に合わせて画面を切り替える（幅600px以下、またはタッチ操作で幅900px以下ならスマホ用）。
操作はすべてメニューに入れ、画面にはカードだけを出す。

| | PC | スマホ |
| --- | --- | --- |
| メニュー | 上部のメニューバー（ファイル / 編集 / ツール / 移動 / スタック。編集とツールは編集中だけ） | 右上の「☰」で一覧 |
| カード名 | カードのタイトルバー | カードのタイトルバー（上部にはスタック名） |
| カード移動 | 移動メニュー、左右の矢印キー | 移動メニュー、左右にスワイプ |
| 部品の設定 | 編集中に部品をダブルクリック、またはツールメニュー | 編集中に部品をダブルタップ、またはメニュー |

### メニューの構成

スタックメニューで「ブラウズ」と「エディット」を切り替える。メニューには、そのモードで使う項目だけを出す。

| メニュー | ブラウズ | エディット（部品） | エディット（絵） |
| --- | --- | --- | --- |
| ファイル | 開く・保存・サンプル | 同じ | 同じ |
| 編集 | － | カード編集 / 背景編集、画像を取り込む、部品を削除、新規カード・カード複製・カードを削除、新規スタック | カード編集 / 背景編集、描画を取り消す・画像を取り込む、新規カード・カード複製・カードを削除、新規スタック |
| ツール | － | 部品の情報、カード・背景・スタックの設定 | カード・背景・スタックの設定 |
| 移動 | カードの移動・戻る | 同じ | 同じ |
| スタック | ブラウズ / エディット、スタック情報、メッセージボックス | ブラウズ / エディット、スタック情報 | 同じ |

「エディット」を選ぶと、前に編集していた層（カードか背景）の部品の編集から始まる。
どの層を編集するかは編集メニューの先頭で選ぶ（カード編集か背景編集か）。
エディット中は道具パレットが出る（PCはカードの左、スマホはカードの下）。先頭の矢印で部品を扱い、ほかの道具で絵を描く。
ボタン・入力フィールド・テキストパーツの追加と、選んでいる部品の削除（ごみ箱のボタン）も、パレットのボタンで行う。
絵を描いている間も部品は表示されるが、押しても反応せず、下の絵に描ける。部品の追加を押すと矢印に、画像の取り込みや文字を選ぶと描画に自動で切り替わる。
部品を選んでいるときは Delete / Backspace で削除できる（確認が出る）。パレットの「完了」でブラウズに戻る。

部品の情報と、カード・背景・スタックの設定はモーダルのダイアログで開く（変更はその場で反映し、OKで閉じる）。
編集中に部品をダブルクリック（ダブルタップ）すると、その部品を同じ層の最前面に移してから部品の情報を開く。重なり順は保存され、スクリプトの `button 2` のような番号も重なり順で決まる。

## スタック情報とスタック設定

スタックメニューの「スタック情報」は、スタック名・ヴァージョン・作者を見るだけのダイアログを出す（ブラウズ中も使える）。

エディット中にツールメニューの「スタック設定…」で、スタック名・作者・ヴァージョン（どちらも自由な文字、60文字まで）、
カードの切り替え効果、beep の音、スタックのスクリプトを設定する。作者とヴァージョンは保存するファイルにも入る。

### スタックのロック

スタックの JSON の `stack` に `"lock": "on"` を書くと、そのスタックは閲覧専用になる。
- エディットできない（スタックメニューの「エディット」が押せなくなり、スクリプトの `doMenu "エディット"` も効かない）。
- 保存できない（ファイルメニューの「保存…」が押せなくなり、`doMenu "保存…"` も効かない）。
- スクリプトがフィールドなどを書き換えても、ほかのスタックを開くときやページを離れるときに「保存していない変更」の確認を出さない。

画面からは付け外しできないので、JSON を直接書き換える。`"on"` 以外の値（`"off"` など）や、項目がないときはロックしない。

```json
"stack": {
  "name": "HOME",
  "lock": "on",
  ...
}
```

## 保存と読み込み

- スタックはブラウザ内に保存しない。残したいときはファイルに保存する。
  ファイルに保存していない変更があるときは、別のスタックを開く前に確認し、ページを閉じる・再読み込みする前にもブラウザが確認する。
- ファイルメニューの「保存…」で、スタックをファイル（既定の名前は `スタック名.stack.json`）に保存する。
  絵もPNGのデータURLとして同じファイルに入る。保存のしかたは端末で変わる。
  - PCのChrome・Edge：OSの「名前を付けて保存」で、保存する場所とファイル名を選ぶ。
  - スマホ：共有シートが出る。iPhoneは「"ファイル"に保存」で場所と名前を選べる（AirDropやメールでも渡せる）。
  - それ以外（PCのSafari・Firefoxなど）と、上の方法が使えなかったとき：ファイル名を聞いてから、ブラウザのダウンロード先に保存する。
    名前が `.json` で終わらなければ `.stack.json` を付ける。
- ファイルメニューの「開く…」で、保存したファイルを読み込む（今のスタックは置き換わる）。
  - PCのChrome・Edge：OSの「開く」画面が、前に「開く…」で開いたファイルのあるフォルダから始まる。
    ブラウザはファイルのパスを教えないので、選んだファイルの手がかり（FileSystemFileHandle）だけを IndexedDB に残す。
  - それ以外：ブラウザの標準のファイル選択。どのフォルダから始まるかはブラウザが決める。

## カードの切り替え効果

閲覧中にカードを移ると、移る先のカードの効果が付く。

- カード設定の「このカードへ移るときの効果」で、カードごとに選べる。
- カードで「スタックの設定に従う」（既定）を選ぶと、スタック設定の「カードの切り替え効果（既定）」を使う（既定はワイプ）。

- ワイプ：次のカードへ進むときは左へ、前へ戻るときは右へ拭き取る。
- ディゾルブ：点々に崩れて入れ替わる。
- なし
- スクリプトで `visual effect` を指定したときは、その効果が優先される（`plain` で効果なし）。
- 編集中・描画中と、端末で「視差効果を減らす」（動きを減らす）を設定しているときは効果を付けない。

## 音

音声ファイルは使わず、ブラウザ（Web Audio）でその場で作る電子音を8種類持つ。

| 名前 | 音 |
| --- | --- |
| `beep` | 短い「ピッ」 |
| `click` | ボタンの「カチッ」 |
| `pop` | 軽い「ポン」 |
| `boing` | 跳ねる「ビョーン」 |
| `chime` | 2音の「ピンポン」 |
| `buzz` | 間違いの「ブブー」 |
| `coin` | 高く上がる「ピロン」 |
| `fanfare` | 短いファンファーレ |

- スクリプト：`play "chime"`（鳴らしたまま次の行へ進む）。
- ボタン情報の「押したときの音」：閲覧中にボタンを押すと、スクリプトより先に鳴る。
- スタック設定の「beep で鳴らす音」：`beep` 命令で鳴る音を選ぶ（既定は `beep`）。
- 設定で音を選ぶと、その場で試しに鳴る。
- iPhoneは本体の消音スイッチがオンだと鳴らない。
- 音を増やすときは `js/sound/SoundPresets.js` に項目（名前・表示名・鳴らし方）を足す。

## メッセージボックス

スタックメニューの「メッセージボックス」で開閉する。スクリプトの `put` で書き込むと開く。
スクリプトでは `msg`・`message`・`message box` で指し、書き込み先にも式の中で中身を読むのにも使える（`put msg & "!" into msg`）。
カード・背景の編集中と描画中は出さない（ブラウズに戻ると、前の状態で出る）。

## カードの複製

エディット中に編集メニューの「カード複製」で、今のカードを丸ごと複製して、すぐ後ろに入れる（名前は「元の名前のコピー」）。
部品・本文・絵・スクリプト・背景フィールドの中身・切り替え効果を写す。背景は元のカードと同じものを使う。

## 背景

全カード共通の層が1つある。エディット中に編集メニューの「背景編集」で切り替える（メニューバーが縞模様になる）。

- 背景に置いた部品と本文は、全カードのカード層の下に表示される。
- 背景のフィールドは、置き場所は共通で中身はカードごと（住所録型）。「全カードで同じ文字にする」をオンにすると中身も共通になる。
- カードを編集しているときの背景の部品は、薄く表示されて触れない。

## 文字の大きさ

ボタンとフィールドは、部品の情報の「文字の大きさ」で文字の大きさ（12 / 14 / 16 / 18 / 24ドット、既定は16）を選べる。
スクリプトでは `set the textSize of field 1 to 20` のように6〜96ドットで指定できる。

## ボタン

ボタン情報の「パーツID」と「ラベル」は別々に決められる。

- パーツIDは部品の名前（`the name`）で、`button "名前"` のようにスクリプトで部品を指すときに使う。ラベルは、ボタンの上に出る文字。
- ラベルは空にもできる（絵の上に透明なボタンを置くときなど）。ラベルが空のボタンは、押したときに黒く反転させず、50%の黒を重ねて下の絵を透かす。
- スクリプトでは `set the label of button "OK" to "はい"`。
- ラベルを持たない古いスタックのボタンは、パーツIDをラベルとして読み込む。

## テキストパーツ（文字を固定したフィールド）

道具パレットの「テキストパーツを追加」で置く。パーツIDは「テキスト1」「テキスト2」…になる。
置いたときのスタイルは「透明」（枠線なし）。
部品の情報は「テキスト情報」になる（入力フィールドは「フィールド情報」）。

- 閲覧中は文字を書き換えられない。文字は編集中にテキスト情報の「テキスト」で入れる。スクリプトの `put` でも書き換えられる。
- 文字の揃え：左揃え・中央揃え・右揃え（置いたときは左揃え）。スクリプトでは `set the textAlign of field 1 to center`。
- スクロールバーを表示（既定はオン）：オフにするとバーを隠す。ホイールや指でのスクロールはできる。スクリプトでは `set the scrollbar of field 1 to false`。
- スクリプト有効（既定はオン）：オンなら押すとボタンと同じくスクリプトが動く。オフなら押しても選ばれず（枠線も出ず）、カードを押したことになる。スクリプトでは `set the clickable of field 1 to false`。
- スクリプトからはフィールドとして指す（`field "テキスト1"`）。`set the lockText of field 1 to false` にすると入力フィールドに変わる。

## 描画

エディット中に道具パレットで描画の道具を選ぶと、カードと背景に白黒の絵を描ける（「カード編集」「背景編集」で描く層を選ぶ）。
パレットの矢印を押すと、同じ層（カードか背景）の部品の編集に戻る。

- 道具：鉛筆、消しゴム、直線、四角、楕円、塗りつぶし、選択。線の太さは 1 / 2 / 4 ドット（消しゴムはその4倍）。
- 選択：ドラッグで四角く囲むと、その範囲のドットを絵から切り取って枠付きで浮かせる（貼り付けた画像や文字、描いた線を後から動かせる）。
  枠のドラッグで移動、右下の四角で大きさ（縦横比は保ち、ぼかさずにドットのまま拡大・縮小）。
  「コピー」で今の位置に写しを残し、浮かせた方は続けて動かせる。「削除」（Delete / Backspace）で捨てる。
  「貼り付け」で確定、「キャンセル」かEscで切り取る前に戻す。囲んでから確定するまでの操作は、1回の取り消しで戻る。
  何も描いていない範囲を囲んでも何もしない。
- 塗りつぶしの模様：黒、白、チェック、縦縞、横縞（1ドットずつ）。塗りつぶしを選ぶと、太さの代わりに模様が出る。
  押した所とつながっている同じ色（黒・白・透明）の部分を塗る。
- 「取消」（⌘Z / Ctrl+Z、編集メニューの「描画を取り消す」）で20回まで戻せる。
- 消しゴムのボタンを2回続けて押す（ダブルクリック・ダブルタップ）と、確認のあと絵をすべて消す。これも取り消せる。
- 画像の取り込み：絵を描いているときに編集メニューの「画像を取り込む…」で写真や画像ファイルを選ぶ。
  アトキンソン方式のディザで白黒にして、枠付きで重ねて見せる。枠のドラッグで移動、右下の四角で大きさ（縦横比は保つ）、
  パレットの明るさ・コントラストで見え方を調整し、「貼り付け」で絵に書き込む（「キャンセル」かEscでやめる）。
  貼り付けた後は描いた絵と同じで、鉛筆や消しゴムで手を入れられ、取り消しもできる。
- 文字を絵として置く：道具パレットの「文字」（A）で、文字（改行できる）とフォント・大きさ・太さを選ぶ。
  フォントはゴシック・丸ゴシック・明朝・等幅、大きさは12〜48ドット、太さは標準・太字。前に選んだものが次の既定になる。
  端末にないフォントは同じ系統の標準のフォントになる（丸ゴシックはMac・iPhone以外ではゴシック）。
  文字を黒、ほかを透明のドットにして、画像の取り込みと同じ枠で位置と大きさを決めて貼る（OKは ⌘Enter / Ctrl+Enter でも押せる）。
- 絵はスタックの大きさ（320×480など）のドットで、黒・白・透明の3つ。白は下の層を隠し、消しゴムは透明に戻す。拡大してもぼかさずに表示する。
- 重なり順は下から「背景の絵 → 背景の本文 → 背景の部品 → カードの絵 → カードの本文 → カードの部品」。
- 絵はPNGのデータURLとして、カード・背景の `picture` に保存する。

カードの大きさはスタックごとに持つ。新しいスタックは縦長の 320×480。

## 構成

ビルドの手順はなく、`index.html` が `js/app.js` を ES モジュールとして読み込む。

### コードの書き方

- 関数は `fs` + 大文字で始まる名前のアロー関数（`const fsGoToCard = (xIndex) => { ... };`）。
- 引数・変数は `x`、モジュール全体の状態は `p` で始める（`p` は効果音の `pSoundPlayer` だけ。アプリの状態は `app.state` の1か所にまとめる）。
- クラスのメソッドとプロパティは、接頭辞なしで役割の分かる名前にする。
- 意味のある数や文字（上限、時間、クラス名、メッセージの名前など）は、名前を付けた定数にする。
  アプリの設定は `js/config/AppConfig.js`、スタックの保存形式に関わるものは `js/model/StackFormat.js`、
  見た目の数は `css/app.css` の `:root` の CSS 変数に置く。
- エラーは `js/diagnostics/Log.js` でコンソールに残し、画面には原因の分かる文で知らせる。

| `EditActions.js` | エディットの操作（ブラウズ・エディットの切り替え、部品とカードの追加・削除、設定の画面） |

## スクリプト

詳しいリファレンス（命令・関数・プロパティ・演算子・制限・例）は [`docs/hycartalk-reference.html`](docs/hycartalk-reference.html) にある。

```
on mouseUp
  add 1 to field "count"
  if field "count" > 9 then
    answer "10回押しました！"
  end if
end mouseUp
```

メッセージは「部品 → カード → 背景 → スタック」の順に渡され、最初に見つかったハンドラが動く。
`pass mouseUp` で次へ渡せる。

### 画面から送られるメッセージ

`mouseUp`（ボタン、文字を固定したフィールド、カードの何もない所）、`openCard`、`closeCard`、`openStack`

### 命令

| 命令 | 例 |
| --- | --- |
| put | `put "こんにちは" into field "msg"` / `after` / `before`。書き込み先を省くとメッセージボックスへ |
| get | `get field 1`（結果は `it`） |
| go | `go next card` / `go prev card` / `go first card` / `go to card "ホーム"` / `go card 2` / `go back` |
| go stack | `go stack "stacks/reference"` / `go to stack "https://example.com/my.stack.json"`。別のスタックを開く。パスは `index.html` から見た位置かURLで、`.json` で終わらなければ `.stack.json` を付ける。Webサーバー上のファイルだけ開ける（パソコンの中のパスはブラウザが読ませない。ほかのサイトのURLはそのサイトがCORSで許しているときだけ）。保存していない変更があれば確認する。スタックが置き換わるので、そのあとの行は実行しない |
| visual | `visual effect wipe left` / `wipe right` / `dissolve` / `plain`（効果なし）。速さ `very fast` / `fast` / `slow` / `very slow` を後ろに付けられる。次の1回の go にだけ効く |
| answer | `answer "保存しますか？" with "いいえ" or "はい"`（押したボタンが `it`） |
| ask | `ask "お名前は？" with "ゲスト"`（入力が `it`、キャンセルで `the result` が `Cancel`） |
| add / subtract / multiply / divide | `add 1 to field "count"` / `multiply x by 2` |
| hide / show | `hide button "ひみつ"` |
| set | `set the name of button 1 to "OK"`（name, label, text, visible, lockText, clickable, sharedText, textSize, textAlign, scrollbar, sound, left, top, width, height） |
| beep / wait | `beep 2` / `wait 1 second` / `wait 30 ticks` |
| play | `play "chime"`（音の名前は上の「音」の表） |
| open url | `open url "https://example.com"`。別のページ（タブ）で開く。開けるのは http / https / mailto / tel のURLだけ。ボタンを押したときのスクリプトで使う（`wait` のあとなどではブラウザに止められることがある） |
| doMenu | `doMenu "開く…"` / `doMenu "サンプルを開く"` / `doMenu "新規スタック…"`。メニュー項目を選んだのと同じ。今は出ていないメニューの項目も選べ、末尾の「…」は省いてよい。カードの移動は `go` を使う |
| send | `send "mouseUp" to button "次へ"` |
| global | `global gScore` |
| 制御 | `if … then … else … end if` / `repeat` / `repeat 5 times` / `repeat with i = 1 to 10` / `repeat while …` / `repeat until …` / `exit repeat` / `next repeat` / `exit mouseUp` / `exit to HyperCard`（`exit to HycarPerd` も可） / `return 値` |

自分で作ったハンドラは命令として呼べる（`on greet who` … `end greet` → `greet "花子"`）。
`function` で作った関数は `double(21)` のように呼べる。

### 式

- 演算子：`+ - * / ^ div mod`、`&`（連結）、`&&`（空白を挟んで連結）、`= <> < > <= >=`、`is`、`is not`、`contains`、`is in`、`and or not`
- 定数：`empty` `true` `false` `return` `space` `tab` `quote` `comma`
- 部品：`field "名前"` / `field 2` / `button "名前"` / `me` / `the target`
  - `card field` / `bg field`（`card button` / `bg button`）で層を指定できる。
  - 指定がなければ、名前のときはカード→背景の順に探す。番号のときはカードの部品。
- 背景：`this background`（`the name of this bg` など）
- プロパティ：`the name of me` / `the visible of field 1` / `the number of this card`
- 数：`the number of cards` / `the number of buttons` / `the number of bg fields` / `the number of words in x`
- チャンク：`word 2 of x` / `char 1 to 3 of x` / `line 1 of field "memo"` / `item 2 of "a,b,c"`（読み取りのみ）
- 関数：`random(6)` `abs` `round` `trunc` `sqrt` `length` `max` `min` `sum` `average` `offset` `charToNum` `numToChar`
- `the date` / `the long date` / `the time` / `the seconds` / `the ticks` / `the result`

全角の数字は数値として扱う。iOSが自動で変換する引用符（“ ”）や「—」のコメントも受け付ける。
