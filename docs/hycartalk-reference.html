1. スクリプトの基本

HycarTalk は、HycarPerd のスタックを動かすスクリプトの言語です。HyperCard の HyperTalk をもとにしています。

スクリプトを書く場所

スクリプトは、エディット中に次の画面で書きます。書くたびに構文が確かめられ、誤りがあれば欄の下に出ます。

持ち主開き方
ボタン・フィールド・テキストパーツ部品をダブルクリック（ダブルタップ）、またはツールメニューの「部品の情報…」
カードツールメニューの「カード設定…」
背景ツールメニューの「背景設定…」
スタックツールメニューの「スタック設定…」

スクリプトはブラウズ中だけ動きます。エディット中はメッセージが送られません。

書き方の決まり

  • 大文字・小文字：区別しません。Put・PUT・put は同じです。部品やカードの名前も、大文字・小文字を区別せずに探します。
  • 1行に1つの文：文は行ごとに書きます。行の先頭の空白（字下げ）は自由です。
  • コメント：-- から行の終わりまでは無視されます。iPhone が自動で変える —（ダッシュ）も使えます。
  • 行の継続：行の終わりに ¬ を書くと、次の行に続けて書けます。
  • 文字：" で囲みます。スマホで入力されがちな “ ” も使えます。文字の中に " を入れるときは、定数 quote をつなぎます。
  • 名前：変数やハンドラの名前には、日本語を含む文字・数字・_ が使えます（数字で始めることはできません）。
on mouseUp
  -- これはコメント
  put "とても長い文は" && ¬
      "次の行に続けて書ける" into field "メモ"
end mouseUp

2. ハンドラとメッセージ

on … end（メッセージハンドラ）

on メッセージ名 [引数1, 引数2, …] 文 end メッセージ名

メッセージを受け取ったときに動く処理です。1つのスクリプトに、いくつでも書けます。引数を書くと、受け取った値がその名前のローカル変数に入ります（渡されなかった引数は空）。

on mouseUp
  answer "押されました"
end mouseUp

function … end（関数ハンドラ）

function 関数名 [引数, …] 文 return 値 end 関数名

式の中で 関数名(引数, …) と書いて呼ぶ、自作の関数です。return で値を返します。組み込み関数と同じ名前なら、自作の方が先に使われます。

function double n
  return n * 2
end double

on mouseUp
  put double(21)   -- 42
end mouseUp

画面から送られるメッセージ

メッセージ送られるとき最初に受け取るもの
mouseUpボタンを押した。スクリプト有効のテキストパーツを押した。カードの何もない所を押した押した部品（何もない所ならカード）
openStackスタックを開いた（ブラウズで開いたときだけ）スタック
openCardカードが表示された（スタックを開いたときは openStack の直後）表示されたカード
closeCardカードを離れる直前離れるカード

ボタンに「押したときの音」を設定していれば、mouseUp より先に鳴ります。スクリプトが動いている間に押しても、次の mouseUp は送られません。

メッセージの通り道

メッセージは次の順に渡され、最初に同じ名前のハンドラを持っていたもので動きます。どこにもなければ何も起きません。

部品 → カード → 背景 → スタック

カードに届いたメッセージは「カード → 背景 → スタック」の順です。スタックのスクリプトに書けば、すべてのカードで動きます。

pass

pass メッセージ名

今のハンドラを終え、同じメッセージを通り道の次へ渡します。

-- カードのスクリプト
on openCard
  put the name of this card into field "見出し"
  pass openCard   -- 背景やスタックの openCard も動かす
end openCard

自作のメッセージ（命令として呼ぶ）

命令の名前の代わりに自作のハンドラの名前を書くと、そのメッセージを自分のスクリプトから通り道に沿って送ります。引数は , で区切ります。どこにもハンドラがなければエラーになります。

on mouseUp
  greet "花子", 3
end mouseUp

on greet who, count
  repeat count times
    put "こんにちは、" & who after msg
  end repeat
end greet

画面から送られるメッセージ（mouseUp・openCard など）は、受け取るハンドラがなくてもエラーになりません。

send

send メッセージ [to オブジェクト]

メッセージ（文字で書く）を指定したオブジェクトに送ります。送り先を省くと、このスクリプトを持つオブジェクトに送ります。

send "mouseUp" to button "次へ"
send "reset" to this card

3. 変数

ローカル変数

宣言は要りません。put 値 into 名前 と書くと、その名前の変数ができます。使える範囲はそのハンドラの中だけで、ハンドラが終わると消えます。

put 3 into count
add 2 to count
put count * 10   -- 50

値を入れる前の変数を読むと、HyperTalk と同じく名前そのものの文字になります（answer abc は「abc」）。打ち間違いに気づきにくいので、使う前に必ず値を入れてください。

it

get・answer・ask の結果が入る特別な変数です。値を入れる前は空です。

ask "お名前は？"
put "こんにちは、" & it

global（グローバル変数）

global 名前 [, 名前 …]

宣言した名前は、すべてのハンドラで同じ値を共有します。使うハンドラのそれぞれで宣言してください。最初の値は空です。

on mouseUp
  global score
  add 1 to score
  put "得点：" & score
end mouseUp

グローバル変数は、スタックを開き直すと消えます。残しておきたい値はフィールドに入れてください（フィールドの中身はスタックと一緒に保存されます）。

メッセージボックス（msg）

msg・message・message box はメッセージボックスを指します。書き込み先にも、式の中で中身を読むのにも使えます。書き込むと、閉じていても開きます（エディット中は表示されません）。

put "1行目" into msg
put return & "2行目" after msg
put the number of lines in msg   -- 2

4. 値の扱い

値は「文字」「数」「真偽値（true / false）」のどれかですが、使う場面に合わせて自動で読み替えます。

場面読み替え方
数として読む（+・add など）前後の空白は無視します。全角の数字（１２）も読めます。空の文字は 0。数として読めなければエラー
真偽値として読む（if・and など）true / false（大文字・小文字は問わない）だけ。ほかはエラー
文字にする（&・表示など）整数はそのまま。小数は 6 桁で丸めます（0.1 + 0.2 は 0.3）。計算できない値は NAN、無限大は INF / -INF
比べる（=・< など）両方が数として読めれば数で、そうでなければ大文字・小文字を区別しない文字で比べます（"10" = 10.0 は true、"ABC" = "abc" も true）

6. 演算子

上ほど先に計算します（優先順位が高い）。同じ段の演算子は左から順に計算します（^ だけは右から）。かっこ ( ) で順番を変えられます。

順位演算子意味例
1-（前に付ける）・not符号を反転・真偽を反転-x、not (a > b)
2^べき乗（右から計算）2 ^ 3 ^ 2 は 512
3*・/・div・mod掛け算・割り算・割り算の整数部分・余り7 div 2 は 3、7 mod 2 は 1
4+・-足し算・引き算1 + 2
5&・&&文字をつなぐ・空白を1つはさんでつなぐ"a" && "b" は「a b」
6=・is・<>・≠・is not・<・>・<=・≤・>=・≥・contains・is in・is not in比べる・含むか（大文字・小文字を区別しない）"Hello" contains "ell"、"b" is in "abc"
7andどちらも true なら true。左が false なら右は計算しないx > 0 and x < 10
8orどちらかが true なら true。左が true なら右は計算しないx = 1 or x = 2

0 で割る（/・div・mod・divide）とエラーになります。

11. 命令

[ ] の中は省けます。| はどれか 1 つを書きます。

put — 値を書き込む

put 値 [into | after | before 書き込み先]

into は置き換え、after は後ろに足す、before は前に足す。書き込み先を省くとメッセージボックスへ書き込みます。書き込み先には、変数・フィールド（ボタンの名前で指した部品の文字も）・msg が使えます。

put "こんにちは" into field "あいさつ"
put "!" after field "あいさつ"
put 42                 -- メッセージボックスへ
put total into result_box

get — 値を it に入れる

get 値
get field "名前"
if it is empty then answer "名前を入れてください"

set — プロパティを変える

set [the] プロパティ of オブジェクト to 値

使えるプロパティは 8. プロパティ を見てください。

set the visible of field "ヒント" to false
set the textAlign of field "見出し" to "center"

add / subtract / multiply / divide — 計算して書き戻す

add 値 to 書き込み先 subtract 値 from 書き込み先 multiply 書き込み先 by 値 divide 書き込み先 by 値

書き込み先の今の値を数として読み、計算した結果で置き換えます。空なら 0 として計算します。

add 1 to field "回数"
multiply total by 1.1
divide x by 4

go — カードを移る

go [to] カード go [to] back

go back は前に表示していたカードへ戻ります（最大 50 枚まで覚えています）。移ると closeCard → openCard が送られます。

go next card
go prev
go to card "目次"
go card 2
go back

go stack — 別のスタックを開く

go [to] stack パス

Web サーバー上のスタックを開きます。パスは index.html から見た場所か、http://・https:// の URL です。名前が .json で終わらなければ .stack.json を補います。保存していない変更があれば、確認が出ます。

go stack "stacks/reference"       -- stacks/reference.stack.json
go stack "https://example.com/my.stack.json"

スタックが置き換わるので、go stack の後の行は実行されません。他のサイトのスタックは、そのサイトが読み込みを許可（CORS）していないと開けません。

visual effect — 次の移動に効果を付ける

visual [effect] wipe left | wipe right | dissolve | plain [[very] fast | slow]

次の 1 回の go（go back も）にだけ効きます。plain は効果なし。指定しないときは、カード設定・スタック設定の効果を使います。

速さvery fastfast（指定なし）slowvery slow
長さ0.15 秒0.25 秒0.4 秒0.7 秒1.1 秒
visual effect dissolve slow
go next card

端末で「視差効果を減らす（動きを減らす）」を設定していると、効果は付きません。

answer — 知らせる・選んでもらう

answer 文 [with ボタン [or ボタン …]]

ダイアログを出し、押されるまで待ちます。押したボタンの文字が it に入ります。ボタンを省くと「OK」だけ。最後のボタンが既定のボタン（Enter で押せる）になります。

answer "保存しますか？" with "いいえ" or "はい"
if it is "はい" then doMenu "保存…"

ask — 入力してもらう

ask 文 [with 最初に入れておく文字]

入力された文字が it に入ります。キャンセルされたら it は空、the result は Cancel になります。

ask "お名前は？" with "ゲスト"
if the result is "Cancel" then exit mouseUp
put "こんにちは、" & it & "さん" into field "あいさつ"

beep — 音を鳴らす

beep [回数]

スタック設定の「beep で鳴らす音」を鳴らします（既定は beep）。回数を書くと、前の音が鳴り終わってから次を鳴らします（最大 10 回）。

play — 名前を指定して音を鳴らす

play 音の名前

音は鳴らしたまま、すぐ次の行へ進みます。使える名前は 14. 音の名前。知らない名前はエラーです。

play "chime"

wait — 待つ

wait [for] 量 [seconds | milliseconds | ticks]

単位を省くと tick（60 分の 1 秒）です。second・secs・sec、millisecond・ms、tick とも書けます。待っている間も、メニューの「ブラウズ」「エディット」で止められます。

wait 2 seconds
wait 30          -- 0.5 秒
wait 250 ms

hide / show — 部品を隠す・出す

hide 部品 show 部品
hide button "答え"
show field "ヒント"

doMenu — メニューの項目を選ぶ

doMenu 項目の名前

メニューを選んだのと同じことをします。名前の末尾の「…」は省けます（"..." でも可）。今のモードで出ていないメニューの項目も選べますが、押せない状態の項目はエラーになります。使える名前は 13. doMenu で選べる項目。

doMenu "次のカード"
doMenu "開く"

項目の処理の終わりは待たずに次の行へ進みます。「ブラウズ」「エディット」を選ぶと、実行中のスクリプトはそこで止まります。

open url — Web ページを開く

open url URL

別のタブ（スマホでは別の画面）で開きます。使えるのは http:・https:・mailto:・tel: だけです。相対 URL は HycarPerd のページの場所が基準です。

open url "https://example.com/"
open url "mailto:someone@example.com"

send — メッセージを送る

send メッセージ [to オブジェクト]

2. ハンドラとメッセージ を見てください。

global — グローバル変数を宣言する

global 名前 [, 名前 …]

3. 変数 を見てください。

return — 関数の値を返す

return [値]

ハンドラを終えます。function ハンドラでは、その値が関数の値になります。値を省くと空。

pass — メッセージを次へ渡す

pass メッセージ名

exit — 途中で終える

exit ハンドラ名 -- このハンドラを終える exit repeat -- いちばん内側の repeat を抜ける next repeat -- repeat の次の回へ進む exit to HyperCard -- 実行中のスクリプトをすべて終える（exit to HycarPerd も可）
on mouseUp
  ask "パスワード"
  if it is not "1234" then exit mouseUp
  go card "秘密"
end mouseUp

12. 制御構文（if・repeat）

if

条件は true か false になる式です（ほかの値はエラー）。

-- 1行で if 条件 then 文 [else 文] -- else を次の行に if 条件 then 文 else 文 -- 複数行 if 条件 then 文 else if 条件 then 文 else 文 end if
if field "点数" >= 80 then
  put "合格"
else if field "点数" >= 60 then
  put "もう少し"
else
  put "不合格"
end if

repeat

repeat [for] 回数 [times] repeat with 変数 = 始め [down] to 終わり repeat while 条件 repeat until 条件 repeat [forever] 文 end repeat
形くり返し方
repeat 55 回（repeat for 5 times とも）
repeat with i = 1 to 10i を 1 ずつ増やしながら、10 を超えるまで。down to なら 1 ずつ減らす
repeat while x < 10条件が true の間（最初に確かめる）
repeat until x >= 10条件が true になるまで（最初に確かめる）
repeat / repeat foreverexit repeat まで続ける
put 0 into total
repeat with i = 1 to 10
  if i mod 2 = 0 then next repeat
  add i to total
end repeat
put total   -- 25（奇数の合計）

終わらないくり返しは、「ブラウズ」「エディット」を選び直すと止まります。止めないままでも、100 万回の文を実行すると自動で止まります。

15. 制限と安全のための決まり

項目決まり
実行できる文の数1 回のメッセージで 100 万文まで。超えると「処理の回数が多すぎるため止めました。」
スクリプトの中断スタックメニューで「ブラウズ」「エディット」を選ぶと止まる（wait の途中でも）
実行中の画面の操作スクリプトの実行中は、ボタンの mouseUp とカードの移動（メニュー・スワイプ・キー）を受け付けない
beep の回数最大 10 回
open urlhttp:・https:・mailto:・tel: だけ（javascript: などは開けない）
go stackWeb サーバー上のスタックだけ（パソコンの中のファイルは開けない）
カードの枚数1 スタック 10 枚まで
エディット中スクリプトは動かず、メッセージも送られない

16. よく出るエラー

エラーが起きると、どのスクリプトの何行目かを添えたダイアログが出て、スクリプトはそこで止まります。

メッセージよくある原因
「end mouseUp」が見つかりません。on に対応する end がない、または名前が違う
「end if」・「end repeat」が見つかりません。複数行の if・repeat を閉じていない
「xxx」という命令はありません。命令の打ち間違い、または呼んだハンドラがどこにもない
「xxx」という関数はありません。関数の打ち間違い、または function ハンドラがない
ボタン「xxx」が見つかりません。パーツIDの違い、カードと背景の取り違え
カード「xxx」が見つかりません。／カード n はありません。カードの名前・番号の違い
「xxx」は数値ではありません。数でない文字で計算した（値を入れていない変数は名前の文字になる）
「xxx」は true でも false でもありません。if の条件が比べる式になっていない
0 で割ることはできません。割る数が 0
ボタン「x」に「xxx」はありません。／「xxx」は変更できません。そのオブジェクトにないプロパティ、読むだけのプロパティを set した
「xxx」というメニュー項目はありません。／今は選べません。doMenu の名前の違い、押せない状態の項目
「xxx」という音はありません。play の音の名前の違い
文字や単語の一部への書き込みは、まだ使えません。put … into word 2 of x のようなチャンクへの書き込み

17. 例

押した回数を数える

-- ボタンのスクリプト
on mouseUp
  add 1 to field "回数"
  if field "回数" >= 10 then
    play "fanfare"
    answer "10回押しました！"
    put 0 into field "回数"
  end if
end mouseUp

おみくじ

on mouseUp
  put "大吉,中吉,小吉,吉,凶" into kuji
  put item random(the number of items in kuji) of kuji into field "結果"
  play "coin"
end mouseUp

クイズ（背景のスクリプトで全カード共通）

-- 背景のスクリプト
on openCard
  put empty into field "答え"
  hide field "正解"
end openCard

on check expected
  if field "答え" is expected then
    play "chime"
    show field "正解"
    wait 1 second
    visual effect wipe left
    go next card
  else
    play "buzz"
  end if
end check

-- 各カードの「答える」ボタン
on mouseUp
  check "東京"
end mouseUp

ストップウォッチ

on mouseUp
  global startTime
  if the label of me is "スタート" then
    put the ticks into startTime
    set the label of me to "ストップ"
  else
    put (the ticks - startTime) / 60 into elapsed
    put round(elapsed * 10) / 10 & " 秒" into field "時間"
    set the label of me to "スタート"
  end if
end mouseUp

ランダムなカードへ移る（同じカードは避ける）

on mouseUp
  put the number of this card into here
  repeat
    put random(the number of cards) into n
    if n is not here then exit repeat
  end repeat
  visual effect dissolve
  go card n
end mouseUp

メッセージボックスに記録を残す

on openCard
  put the time && the name of this card & return after msg
  pass openCard
end openCard
